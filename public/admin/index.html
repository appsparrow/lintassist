⚠ CORS Error — file:// origin blocked
Browsers block requests from files opened directly (file://).
Fix: serve this file from a local server. Pick any one:
# Python (built-in, no install):
python3 -m http.server 8080

# Then open: http://localhost:8080/admin.html
Or install the Live Server extension in VS Code and click "Go Live".
⚠ Could not reach the worker
This page loaded fine — the request to the Worker URL above is what failed. Common causes:
  • The Worker URL is wrong, or missing https://
  • The worker isn't deployed (wrangler deploy)
  • A browser extension (ad blocker, privacy/tracker blocker) is blocking the request
  • No network connection right now, or the worker is temporarily down
Open DevTools → Network, retry, and check the failed request's status for the exact cause.
