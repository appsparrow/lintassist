# Security Policy

LintAssist is an independent, solo-developer project (a web app and
Figma plugin for AI-assisted design review). There's no dedicated
security team, but reports are taken seriously and addressed promptly.

## Reporting a Vulnerability

Please report security issues privately rather than opening a public
GitHub issue:

- **Preferred:** use GitHub's private vulnerability reporting for this
  repository — go to the **Security** tab →
  **Report a vulnerability**. This opens a private conversation visible
  only to the maintainer until it's resolved.
- **Alternative:** open a regular GitHub issue at
  [github.com/appsparrow/lintassist/issues](https://github.com/appsparrow/lintassist/issues)
  with minimal detail and a way to reach you, and a private channel
  will be set up to discuss specifics.

Please include:
- A description of the issue and its potential impact.
- Steps to reproduce, if possible.
- Any relevant logs, screenshots, or request/response examples (with
  personal data redacted).

## What to expect

- Acknowledgement of your report as soon as possible.
- An honest assessment of severity and a fix timeline once the issue
  is understood — this is a small project maintained by one person, so
  timelines are best-effort, not contractual.
- Credit in the fix's changelog/commit, if you'd like it and once the
  issue is resolved.

## Scope

Covers the LintAssist web app, Figma plugin, and backend Worker in
this repository. Third-party services LintAssist depends on
(Cloudflare, OpenRouter, Anthropic, Stripe) have their own security
policies and should be reported to them directly.
